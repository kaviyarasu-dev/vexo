## 4. Recommended Daily Trading Routine (பரிந்துரைக்கப்படும் தினசரி முறை)

1. **Morning Auth Check (காலை 08:30 IST):**
   - Run `.\start_server.bat` and open `http://localhost:8000`.
   - Topbar-ல் `🔑 Token: >10h` பச்சை நிறத்தில் உள்ளதா என சரிபார்க்கவும்.
2. **Pre-Market Screening (காலை 09:00 IST):**
   - Screener பகுதிக்கு சென்று **Volume Spike** அல்லது **52-Week High** பில்டரை இயக்கி கவனிக்க வேண்டிய பங்குகளை கண்டறியவும்.
3. **Intraday Charting (காலை 09:15 - 03:30 IST):**
   - `Ctrl + K` மூலம் பங்கைத் திறந்து, `5m` அல்லது `15m` timeframe தேர்வு செய்து VWAP மற்றும் EMA கோடுகளை கவனிக்கவும்.
4. **F&O Analysis (மார்க்கெட் நேரத்தில்):**
   - Options டேபில் சென்று Nifty/BankNifty-ன் Max Pain மற்றும் Strike Open Interest மாற்றங்களை கண்காணிக்கவும்.
5. **Post-Market Journaling (மாலை 04:30 IST):**
   - Fyers-ல் இருந்து `tradebook.csv` டவுன்லோட் செய்து, Trade Journal-ல் 1-Click Upload செய்யவும். உணர்ச்சிவசப்பட்டு செய்த தவறுகளுக்கு Mistake Tags சேர்க்கவும்.
