Platform Overview & Architecture

#overview

Institutional Local-First Architecture

VECTORIZED OLAP

The NSE Quant Platform is engineered as a high-speed, local-first research terminal. It pulls raw 1-minute and 1-day candles from Fyers API v3 into an embedded DuckDB database, resamples timeframes in microseconds, and streams analytics into a zero-latency TradingView canvas.

[Fyers API v3 WebSocket / REST] │ (1m Candles & Quotes) ▼ [FastAPI Rate Governor & Security Vault] │ (Worker Process = 1) ▼ [Embedded DuckDB Storage (data/market_data.duckdb)] │ (Microsecond In-Memory Vector Resampling) ├──► [1m, 3m, 5m, 15m, 1h, 1D OHLCV Bars] ├──► [AI Conformal Corridor Engine (LightGBM)] ├──► [OrderBlock Absorption & Volume Footprint] └──► [Black-Scholes Options Greeks Engine] │ ▼ [TradingView Lightweight Charts (v4.2.1) + Web UI]
Trader Edge: Because data is stored and processed locally on your machine, charts, screeners, and backtests execute instantly without lag, cloud downtime, or recurring third-party API subscription costs.

Fyers API & Session Management

#fyers-auth

Dual-Token OAuth 2.0 Security

ACTIVE SESSION

Fyers API v3 operates on a dual-token model. An Access Token grants market data queries for 24 hours (until 06:00 AM IST), while a Refresh Token remains valid for 15 days, enabling silent daily renewals without requiring manual login.

Token Type Validity Duration Storage Location Renewal Workflow
Access Token Daily (~06:00 AM IST) OS Keyring / AES-256 Vault Auto-refreshed via Refresh Token
Refresh Token 15 Calendar Days Windows Credential Manager Interactive login: python -m scripts.auth_cli --login
Top Bar Auth Countdown: The top bar displays your remaining token life (e.g. 🔑 Token: 14h 22m). If the session expires, click the badge or run the login CLI.

Options Trading & Greeks Lab

#options

Black-Scholes Mathematical Engine

#options-greeks

Calculates theoretical option pricing and real-time sensitivity Greeks using the Black-Scholes-Merton model calibrated against the RBI 91-Day Treasury Bill risk-free rate.

Greek Symbol Greek Name What It Measures Target for Buyers / Sellers
Δ (Delta) Price Sensitivity ₹ Change in option price per ₹1 move in spot Buyers want high Delta (0.5 to 0.8) for quick price expansion.
Γ (Gamma) Delta Acceleration Rate of change of Delta per ₹1 move in spot High near ATM strikes; triggers gamma squeezes on expiry days.
Θ (Theta) Time Decay ₹ Loss in option value per elapsed calendar day Option sellers profit from negative Theta decay.
ν (Vega) Volatility Sensitivity ₹ Change in option price per 1% change in IV Buy options before expected volatility spikes (e.g. RBI policy / earnings).
