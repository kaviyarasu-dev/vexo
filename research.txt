from fyers_apiv3 import fyersModel

# Step 3-la generate aana keys-a inga podaanum
client_id = "UNGA_API_KEY-100"

# Data request pandradhukana details
data = {
    "symbol":"NSE:SBIN-EQ",

    "range_to":"2023-12-31",

# API call

fyers la Iruka api use pani na yendha stock oda complete data um extract panika mudiyuma?

Aama, extract pannalam. NSE and BSE-la actively trade aagura almost ella stocks, indices (Nifty, BankNifty), and commodities-kum data kedaikkum.

Aana "complete data" nu varumbodhu sila practical limitations and rules irukku:

1. Enna Data Kedaikkum? (Available Data)
Instruments: NSE Equity (ella shares), Indices, and Continuous Futures.

Data Format: OHLCV (Open, High, Low, Close, Volume) candle data mattum dhaan kedaikkum.

Daily Candles (EOD): Oru stock stock exchange-la list aana date-la irundhu 15 to 20+ years data kedaikkum.

Intraday Candles (1 min, 5 min, etc.): Past 3 to 5 years intraday candle history kedaikkum.

2. Sila Mukkiyamaana Limitations (Gavanikka Vendiyavai)
Orey Request-la Ellam Varaadhu (Pagination/Chunking):
Oru single API call-la ungalal 5 varusha 1-minute data-va orey adiya edukka mudiyaadhu.

1-minute candle-ku oru call-ku max 100 days dhaan limit.

Adhanaala neenga code-la while loop pottu, 100-100 days-ah date range maathi maathi chunk panni dhaan full history-a download panna mudiyum.

Rate Limits:
API-la second-ku 5 to 10 requests dhaan anuppa mudiyum. Neenga loop-a romba speed-a run panna 429 Too Many Requests error varum. So, unga code-la chinna delay (e.g., time.sleep(0.5)) vekkanum.

Tick-by-Tick Data Kedaikkadhu:
Idhula candle data (OHLC) mattum dhaan kedaikkum. Past tick-by-tick order book data (Level 2 / Level 3 buyer-seller bids) historical API-la kedaikkadhu.

Expired Options Data Limited:
Equity stocks-ku complete data kedaichidum. Aana expired Options contracts (strike prices) oda pazhaya data eduppadhu romba limited.

Neenga stocks-oda Daily data (10+ years) alladhu 1-minute intraday data (past 2-3 years) edukka ninaikireenga na, Fyers API-la loop ezhudhi neat-ah full data-vaiyum CSV/Database-la save pannikkalam.
